How it works

    

      
The basics

      
    
        
  1. Open the web form you want to test in the current tab.
    2. 
        
  2. Optional: press Scan page to see what the extension found.
    3. 
        
  3. Pick what kind of data you want, then press Fill the form.
    4. 
        
  4. Check the page. Submit it yourself, or let step 3 press the button for you.
    5. 
      

      
Which option should I pick?

      

        
Quick fill
Realistic fake data everywhere. Use this most of the time.

        
Valid data
Correct values only, to confirm the form accepts good input.

        
Wrong data
Bad values, to check the form shows clear error messages.

        
Edge cases
Very short/long and min/max values, to check limits.

        
Full QA run
Tries all of the above in turn, then shows buttons to download the HTML report, the JSON data and (when activity capture is on) a page screenshot — only the ones you pick.

      

      
Is it safe?

      
All values are fake. Nothing is submitted unless you turn that on. Page actions start in Preview only mode, and buttons such as Delete, Remove, Cancel, Back, Reset, Log out, Pay and Checkout are always skipped. Use test or staging sites, never production.

      
Something isn’t working?

      
    
        
  • “Can’t read this page” – reload the website tab, then try again. Browser pages such as chrome:// and the Web Store can’t be used.
    • 
        
  • A button is greyed out – hover over it to see why.
    • 
        
  • A field was skipped – some custom widgets can’t be filled automatically. Fill those by hand.
